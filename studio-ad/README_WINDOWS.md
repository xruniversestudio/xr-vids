# رندر فيديو XR Universe Studio على Windows

هالخطوات بتطلع **النسختين** (الطولية للريل والعرضية) مع الموسيقى. الرندر بيستعمل كرت الشاشة بجهازك، فبيكون أسرع بكتير من السيرفر.

---

## مرّة وحدة بس: التجهيز

### 1) نزّلي Node.js
- افتحي https://nodejs.org ونزّلي نسخة **LTS** (الزر الأخضر).
- ثبّتيها بالإعدادات الافتراضية (Next ← Next ← Install).

### 2) نزّلي المشروع
- **الأسهل:** وأنتِ مسجّلة دخول بـGitHub، افتحي هالرابط وبينزل ملف ZIP:
  https://github.com/xruniversestudio/xr-vids/archive/refs/heads/claude/dazzling-goldberg-qv88hu.zip
- فكّي الضغط بأي مكان، مثلاً على سطح المكتب.
- **أو** إذا عندك Git:
  ```
  git clone -b claude/dazzling-goldberg-qv88hu https://github.com/xruniversestudio/xr-vids.git
  ```

> ما في داعي تنزّلي ffmpeg، لأنه بينزل تلقائياً مع المكتبات.

---

## الرندر

### الطريقة الأسهل: دبل كليك
افتحي مجلد **`studio-ad`** واعملي دبل كليك على **`render_windows.bat`**.

- **أول مرة:** بينزّل المكتبات والمتصفح اللي بيرندر فيه، وهالشي بياخد كم دقيقة حسب سرعة النت.
- **بعدين:** بيرندر النسختين وبيركّب الموسيقى.
- **لما يخلص:** بيفتحلك مجلد **`out`** وفيه الفيديوهين:
  - `XR_Universe_Services_1080x1920.mp4` (ريل)
  - `XR_Universe_Services_1920x1080.mp4` (عرضي)

### أو من الـTerminal
افتحي المجلد `studio-ad`، واكتبي `cmd` بشريط العنوان فوق واضغطي Enter، وبعدين:
```
npm install
npx playwright install chromium
npm run render
```

**أوامر إضافية:**
| الأمر | شو بيعمل |
|---|---|
| `npm run render:v` | النسخة الطولية بس |
| `npm run render:h` | النسخة العرضية بس |
| `npm test` | تجربة سريعة: أول ثانيتين من الطولية، لتتأكدي إنه كل شي شغّال |
| `node render_all.js --workers 2` | عدد المتصفحات اللي بتشتغل سوا لكل نسخة. خففيه إذا الجهاز عم يعلّق، وزيديه إذا قوي |

---

## إذا صار في مشكلة

- **الفيديو طالع أسود أو فاضي:** كرت الشاشة ما اشتغل مع المتصفح. جربي الرندر البرمجي، بس هو أبطأ:
  ```
  set SWIFTSHADER=1 && npm run render
  ```
- **`'npm' is not recognized`:** سكّري نافذة cmd وافتحيها من جديد بعد تثبيت Node.js، أو أعيدي تشغيل الجهاز.
- **`EADDRINUSE` أو port مستعمل:** في رندر تاني شغّال. سكّريه وجربي مرة تانية.
- **الجهاز تقل كتير:** استعملي `node render_all.js --workers 1`.

## شو بيصير بالضبط؟
- `render.js` بيفتح المشهد `ad.html` بمتصفح مخفي، وبيصوّر كل فريم من الـ1122 فريم (37.4 ثانية × 30 فريم بالثانية).
- `render_all.js` بيقسم الفريمات على كذا متصفح بنفس الوقت، وبيجمع المقاطع، وبيركّب الموسيقى `audio/music_ad.wav`.
- كل الحركة محسوبة بدقة من الوقت، بلا عشوائية، فكل مرة بتطلع النتيجة نفسها بالضبط.
